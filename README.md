# HotelStay – Hotel Booking Website

HotelStay is a hotel discovery and reservation website developed to provide users with a simple and convenient way to explore accommodation options. The website showcases different hotels and room categories, allowing visitors to view room information, compare prices, and access booking-related pages.

The project focuses on creating a clean, user-friendly interface with organized navigation and a straightforward hotel browsing experience.

## Live Demo

Visit the website: https://sirdrick037-svg.github.io/Hotel-Stay/

## Project Features

- **Homepage:** Introduces the HotelStay platform and highlights popular accommodation options.
- **Hotel Listings:** Displays featured hotels with images, locations, and nightly prices.
- **Room Listings:** Showcases different room categories, including Standard, Deluxe, Suite, and Family Rooms.
- **Room Details:** Provides information about room features, amenities, and pricing.
- **Booking Page:** Includes a booking form for customer details, check-in and check-out dates, and room selection.
- **User Authentication Pages:** Includes login and registration interfaces.
- **Booking Confirmation:** Provides a dedicated booking confirmation page.
- **Admin Dashboard:** Includes a dashboard interface with booking, customer, room, payment, and reporting sections.
- **About and Contact Pages:** Provides additional information about the website and contact details.

## Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layout, and visual presentation.
- GitHub Pages – Website hosting and deployment.

## Getting Started

To view the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/sirdrick037-svg/Hotel-Stay.git
   ```

2. Open the project folder:

   ```bash
   cd Hotel-Stay
   ```

3. Open `index.html` in your preferred web browser.

No additional installation is required for the basic HTML and CSS website.

## Project Purpose

HotelStay was developed as a web development assignment to demonstrate website structure, styling, page organization, and the design of a hotel browsing and reservation interface.

The project provided an opportunity to practice building multiple interconnected website pages and presenting information in a clear and accessible format.
